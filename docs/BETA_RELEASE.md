# 0.2.0-beta.1 发布说明

这是 AI Video Generator 的早期 Beta 测试版本，不是稳定版，也不适合作为生产环境或唯一数据来源。

本版本冻结当前功能范围，仅用于验证从项目记忆、分镜、素材、H3 提示词、ComfyUI 任务到视频交付的完整工作流。测试数据、提示词、任务状态和媒体产物都可能因为缺陷而需要重新创建。

## 已知风险

- LLM 输出、流式连接和不同 OpenAI-compatible 网关之间仍可能出现兼容性问题。
- 素材重新绑定、提示词重生成和已经编译的任务计划之间可能需要用户手动重新创建任务。
- H3 长镜头、Motion Context 续段、参考图身份一致性和多参考素材仍需要逐项目验证。
- 单 GPU 工作流默认串行；高分辨率、长时长或高显存占用任务可能失败、超时或需要重试。
- ComfyUI、模型、节点、VAE、工作流版本不匹配时，错误信息可能不够明确。
- 后处理工作流依赖用户上传和批准的 ComfyUI API 工作流；部分后处理能力仍未达到稳定可用状态。
- 任务取消、暂停、重启恢复和批量工作台在异常关闭、网络中断或后台进程重启后仍可能需要人工检查。
- UI 可能出现状态刷新延迟、局部内容暂时回退或错误提示不准确。
- Windows 安装包未签名，首次运行可能触发系统安全提示。

## 使用建议

1. 使用可重新生成的测试项目，不要把唯一原始素材交给本版本管理。
2. 每次修改分镜、素材绑定、提示词或工作流后，检查下游提示词和任务计划是否需要重新创建。
3. 遇到失败时保留任务 ID、项目修订号、Harness 修订号和控制平面日志，再执行重试或清理。
4. 低分辨率、短时长、单 GPU 串行运行，避免同时提交多个高负载任务。

反馈应附带项目修订号、任务 ID、错误原文和相关日志；不要上传 API Key 或未脱敏的私密素材。
