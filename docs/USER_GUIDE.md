# AI Video Generator 使用说明

## 1. 先了解 Beta 状态

当前版本是 `0.2.0-beta.1`。它可以完成从创意到视频交付的完整流程，但仍可能出现生成失败、状态刷新延迟、任务恢复异常和参考素材绑定问题。请使用可以重新生成的测试项目，不要把唯一原始素材作为唯一备份。

## 2. 首次启动

1. 双击项目目录中的 `start-app.bat`。
2. 等待控制平面和网页界面都显示在线。
3. 如果出现首次运行检查，先打开“全局设置”。
4. 配置 LLM 服务的兼容接口地址、模型和 API Key。
5. 配置 ComfyUI 地址，并点击测试连接。
6. 在 H3 工作流区域确认扩散模型、文本编码器、视频 VAE 和音频 VAE 可用。
7. 安装或批准 H3 Harness 后，再开始创建项目。

API Key 只在本机凭据存储中使用。不要把密钥写入项目说明、截图或反馈日志。

## 3. 创建项目

点击顶部“新建”，填写项目名称、画幅、帧率和目标时长，然后选择执行方式：

- “精细化模式”适合逐项检查和手动派发。
- “批量模式”适合一次准备多个项目后统一排队。

项目内容会自动保存为修订。项目管理页可以切换项目、清除任务或删除项目。清除任务会保留项目内容、素材和媒体文件；删除项目会删除项目记录，但内容寻址媒体文件可能仍保留在磁盘上。

## 4. 按制作流程工作

### 项目配置

确认画幅、帧率和目标时长。H3 片段使用 24fps；高分辨率和长时长会显著增加显存与内存压力。

### 创意设定

填写核心创意、类型、视觉风格和目标观众。可以上传图片、视频或音频参考，并在文本中使用 `@素材名` 引用。

项目负责人可以根据项目记忆生成或修改内容。AI 生成的修改会先显示在对话区域，确认后才会应用。

### 故事大纲

填写故事段落及其时长。段落总时长应接近项目目标时长。可以手动输入，也可以让项目负责人生成初稿；两种方式最终都保存为同一种项目数据。

### 电影分镜

为每个镜头填写标题、画面摘要、运镜、时长和 Seed。长镜头可以打开 Motion Context 分段，手动填写每段时长和动作；也可以让 AI 自动规划。每段通常为 4 到 12 秒，首段最多 15 秒，分段时长总和必须等于镜头时长。

### 素材与参考图

素材阶段分为两部分：

1. 上方是“分镜素材引用”，按分镜显示该镜头使用的素材。
2. 下方是集中素材库和 AI 素材需求。

可以在“分镜素材引用”中勾选或取消素材。一个素材可以被多个镜头引用，不需要重复上传或创建多个素材需求。AI 会根据创意、大纲和分镜自动生成素材需求，并返回每项需求的镜头引用；用户可以手动修正。

上传素材填充 AI 素材需求后，旧的视频提示词和已编译任务可能失效。此时应重新生成视频提示词，并重新创建任务计划。

### 提示词设计

图片提示词和 H3 视频提示词都可以手动编辑，也可以使用 AI 填入文本框。

- 图片提示词支持“生成全部图片提示词”，请求会并发执行。
- H3 支持“生成全部视频提示词”，不同 Motion Context 片段会并发执行。
- 流式内容会实时写入文本框；文本框中的最终英文内容才是执行事实源。
- 中文对照是可选的，不参与 H3 执行。

如果修改了分镜、参考素材、Seed 或提示词，先确认下游提示词和任务计划是否需要重新创建。不要直接使用绑定变更前的旧任务。

### 视频生成

点击“创建计划并开始生成”或先点击“仅创建任务计划”。生成页会实时显示视频产物和层级进度：项目 → 分镜 → 连接段。

- “暂停”只停止继续派发，不会强制终止已经运行的任务。
- “取消运行任务”会取消当前项目的排队或运行任务。
- 任务页可以单独取消任务、重试失败任务或清除全部任务。
- 重新开始会重新读取全局 H3 设置并重建视频任务。

生成和审核已经合并。AI 审核只提供建议；人工可以标记返工并统一确认。标记返工会冻结对应连续序列，返工成功后新视频会成为活动版本，并显示第几次生成。

### 批量工作台

在项目准备好大纲、分镜和素材后进入“批量工作台”：

1. 选择要加入的项目。
2. 设置优先级和执行方式。
3. 启动或暂停批量执行。
4. 在项目行中查看生成、失败、返工和取消状态。

批量调度按 Motion Context 深度推进。一个序列被冻结时，其他序列仍可继续。关闭页面不会主动停止后台调度，但 Beta 版本重启恢复仍应人工检查。

### 后处理与交付

后处理工作流必须由用户上传 ComfyUI API JSON，再选择用途：视频超分/修复、视频插帧或语音识别/字幕。可以请求 LLM 协助识别输入视频、模型、倍率、目标帧率和语言，也可以手动确认映射。

登记完成后，在交付页选择对应工作流并打开开关。没有上传并批准相应工作流时，不要打开对应后处理选项。最终导出只会使用完整、连续且没有未决返工的活动视频链。

## 5. 常用任务操作

- 任务卡显示“等待依赖”：前置任务尚未完成，不能直接执行。
- 显示“等待派发”：任务已准备好，但还没有被调度器派发。
- 显示“执行中”很久：先查看 ComfyUI 和控制平面日志，再决定等待、取消或重试。
- 显示“失败”：保留错误原文和任务 ID，然后重试；不要连续点击多次。
- 需要从头重做：先使用“清除所有任务”，再重新创建任务计划。

## 6. 故障反馈

反馈问题时请提供：项目名称和修订号、任务 ID、片段 ID、错误原文、发生阶段、是否刚修改过素材或工作流，以及对应的 `data/logs/control-plane-*.stdout.log` 和 `stderr.log` 片段。

不要提供 API Key、完整未脱敏项目记忆或不应公开的原始素材。
