# 修复版本运行与验收说明（2026-09-24）

本文件记录当前源码的操作约定，不代表真实 GPU 或长时间运行验收通过。

## 状态和处理入口

| 状态 | 含义 | 操作 |
| --- | --- | --- |
| blocked | 依赖或审核尚未满足 | 查看依赖对象，处理上游 |
| ready / queued | 已准备或等待领取 | 暂停、取消；暂停范围在命令中明确指定 |
| running | 当前尝试持有执行权 | 查看活动时间；取消先发出停止请求 |
| recovering | 观察既有执行或补收集产物 | 不代表重新生成 |
| retry_wait | 已确认可重试，等待持久化退避 | 不重置次数和绝对截止时间 |
| cancelling | 尚未确认外部执行停止 | 继续对账，不清除记录 |
| needs_attention | 无法安全推断外部结果或输入需修复 | 重新对账；明确确认重复执行风险后才可重提 |
| cancelled | 停止已经确认或从未提交 | 不由恢复流程自动复活 |

任务页以服务端 `available_actions` 为准。重试失败、恢复派发、重新生成是不同操作。
项目、批次、成员暂停只停止新的领取，已经提交的执行继续观察和收尾。
结构化批量命令包含作用范围、对象 ID 和幂等键，并逐项返回结果。
取消响应不等于停止成功。清除历史拒绝仍在恢复、取消或待处理的任务，并保留媒体。

## 升级与回滚

1. 暂停派发，核对所有本地及远程外部任务，停止控制服务后升级源码。
2. 已有 v6/v7 控制库使用 SQLite backup API 创建同目录 `.pre-v8.bak`，增量增加恢复表，保留任务与 prompt 关联。v8 可重复打开；未知新版本拒绝打开。
3. 媒体目录和素材索引应一并保留。不要复制正在写入的裸数据库文件作为备份，不要用重置数据库解决迁移问题。
4. 升级失败时保持服务停止，保存失败库及日志。在确认没有新增外部任务后，从对应一致性备份恢复代码和控制库。
5. 新版本开始执行后，不能直接用旧库覆盖：先对账新产生的 prompt 和产物，避免重复生成。

迁移保留性、备份版本、未来版本拒绝、检查点重复登记、SQLite 连接释放均有自动回归。
完整迁移中途故障回滚演练尚未验收。

## 远程 Worker

Worker 工作目录增加 `execution-journal.sqlite3`。提交意图、attempt、submission token、原始截止时间在提交前持久化。
回包丢失先查询 token；产物以临时文件校验后原子发布，并记录哈希。相同尝试重启可续租后重新观察，不能重复提交。
取消必须携带当前 attempt 和停止证据；未知停止结果保留 cancelling，陈旧回调拒绝发布。

远程租约已过期的尝试会被隔离，禁止盲目重放。目前尚缺完整的过期尝试专用远程观察/人工收集接口；真实远程恢复不应视为全部完成。

## LLM 调用清单

| 调用 | 输入 / 输出 | 触发与失败处理 | 程序负责部分 |
| --- | --- | --- | --- |
| 项目结构化创作 | 当前允许修改的内容和相关素材 / 有约束的 patch | 显式创作或缺失内容；非法引用、锁定字段、结构错误拒绝提交 | ID、机械字段、引用校验和 patch 应用 |
| 图片提示词 | 当前素材规划及相关镜头、引用 / 提示词文本 | 缺失或输入指纹变化；锁定内容保留；并发提交核对输入版本 | 尺寸、版本、绑定、指纹、工作流注入 |
| H3 提示词 | 当前片段、相关素材和前驱语义 / 可执行提示词 | 复用有效指纹；确定性检查后最多一次具体错误修复 | 帧数、约束、标签校验、DAG 和调度 |
| 语义审核 | 配置允许的媒体证据 / 评价 | 依项目审核策略，禁用时只执行确定性检查 | 文件/媒体完整性检查和状态转换 |

一次逻辑操作默认最多 3 次 HTTP 请求、1 次业务修复、300 秒总时限。流式回退和传输重试共享预算，默认提供者并发为 2。
上下文、输出 token/字符和媒体数量有上限。预算测试采用模拟服务，没有真实付费调用。
LLM 预算属于一次执行尝试；任务层尝试预算由 SQLite 管理。交互流断线只重接当前服务进程中的流，不等于跨进程重播 LLM。
